name: Reference fidelity
description: How to treat the user's approved visual references for Tanda.
---
When the user says to match the Tanda picture exactly, reproduce its composition, density, rounded typography, coral accents, illustration and card treatment rather than inventing another direction.

**Why:** The user repeatedly rejected loose editorial reinterpretations and replacement artwork, saying “do exactly as in the picture.”

**How to apply:** Use the supplied artwork when available and keep semantic text and working controls separate. The latest explicit reference takes precedence over earlier stylistic choices.
