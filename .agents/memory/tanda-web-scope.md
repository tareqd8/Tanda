name: Tanda web scope
description: Product boundary between the Tanda website and its separate mobile app.
---

**Rule:** The website is a bilingual marketing landing page for Tanda. App functionality such as browsing, searching, saving, and redeeming deals belongs in the separate mobile app.

**Why:** The user explicitly clarified that the website is landing-page-only because Tanda will have a mobile app.

**How to apply:** Keep website updates focused on introducing and promoting the app. Use app screenshots as brand and product-preview references, not as instructions to make the website itself a functional mobile-app interface.
