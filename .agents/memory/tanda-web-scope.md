**Rule:** The website is a bilingual marketing landing page for Tanda, with a separate protected admin page for managing its public logo. Consumer features such as browsing, searching, saving, and redeeming deals belong in the mobile app.

**Why:** The user clarified the site is landing-page-only because Tanda will have a mobile app, and requested a private portal for logo uploads and changes.

**How to apply:** Keep public website updates focused on introducing and promoting the app. Keep the admin portal limited to site-brand management unless asked otherwise. Use app screenshots as brand and product-preview references, not as instructions to make the website itself a functional mobile-app interface.
